# Roadmap

Plannen kunnen wijzigen. Vinkjes volgen [docs/STATUS.md](docs/STATUS.md); open punten (zoals Docker/Ubuntu-documentatie) zijn nog in bewerking.

## MVP

- [x] Adviesengine (uitlegbaar, configureerbare drempels)
- [x] MET Norway
- [x] Open-Meteo
- [x] Bright Sky
- [x] KNMI-waarnemingen
- [x] Weather Underground PWS (adapter)
- [x] Meerdere auto's
- [x] Bandensets
- [x] Wisselhistorie
- [x] Garageplanner

- [x] Beheerinterface
- [x] Landelijk advies

- [x] Docker + Debian/Ubuntu-LXC
- [x] Tests + documentatie
